# Мобилка

Источник правды — раздел «Mobile CSS architecture» в `DESIGN-SYSTEM.md`. Коротко:

- Все мобильные правила — только `mobile.css`, один `@media (max-width: 767px)`, секции в порядке страницы.
- Без `!important`, без inline-стилей, без новых токенов, без правок `styles.css` / `design-system.css`.
- Разметка, нужная только на телефоне, создаётся скриптом на брейкпоинте и убирается за ним (как `marquee.js`).

**После каждой правки проверить:** 375 px, 767 px, 768 px (десктоп не поехал), 1440 px, анимации.
В отчёте — какие файлы изменены. Коммит.
