# Вычитка текстов

1. Взять текущий текст из `index.html` (не из памяти и не из Figma — сайт уже живёт в коде).
2. Проверить: факт есть в `cases/` со статусом ✅/≈; метрика относится к этому проекту; нет QA-прошлого; почта публичная.
3. Стиль: короткие фразы, глагол действия, без «helped to / was responsible for»; курсив — панчлайн заголовка.
4. Выдать списком: **было → стало → зачем**. Ничего не менять до «измени / пиши».
5. Внесла — коммит «Тексты: <где>», проверить десктоп и мобилку глазами.
