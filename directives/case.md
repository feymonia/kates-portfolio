# Кейс v2

**Вход:** файл `cases/<проект>.md` + черновик v2 из `~/Documents/Kates Portfolio/cases/` + картинки в Figma.

1. Собрать в `cases/<проект>.md` всё, что известно, со статусами ✅ / ≈ / ⏳. Чего нет — записать вопросом в `open-questions.md`, не придумывать.
2. Структура кейса (английский):
   - **Context** — продукт, пользователь, почему это важно бизнесу. 2–3 предложения.
   - **Problem** — что ломалось, с цифрой, если есть.
   - **My role** — роль, команда, сроки. Только подтверждённое.
   - **Constraints** — что ограничивало решения.
   - **Decisions** — 2–4 ключевых решения: что выбрали, от чего отказались и почему. Каждое — с картинкой.
   - **Impact** — метрики ✅/≈; если метрик нет — качественный итог без цифр.
3. Цифры: «≈» → формулировка «about / ~», не усиливать. ⏳ на сайт не идёт.
4. Показать Кате текст целиком в чате; в HTML вносить только после «пиши».
5. После внесения — `pre-publish.md`, коммит.
