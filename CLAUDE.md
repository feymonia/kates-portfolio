# Портфолио Кати Бабенко — рабочий хаб

Личный сайт-портфолио продуктового дизайнера. Сайт — статический HTML/CSS/JS в этой папке.
Язык сайта — **английский**. Язык рабочих файлов (этот, бриф, кейсы, вопросы) — русский.

## Где что

| Файл | Что внутри |
|---|---|
| `brief.md` | для кого сайт, позиционирование, план v1 → v2 |
| `cases/*.md` | по файлу на проект: факты, метрики со статусом, что на сайте, ссылки на Figma |
| `open-questions.md` | открытые вопросы к Кате; закрытый вопрос → ответ переносится в кейс/бриф |
| `directives/*.md` | процедуры: как писать кейс, вычитывать тексты, делать мобилку, проверять перед публикацией |
| `DESIGN-SYSTEM.md` | токены, компоненты, архитектура мобильного CSS — источник правды по виду |
| `index.html`, `styles.css`, `design-system.css`, `mobile.css`, `*.js` | сам сайт |

Макет: https://www.figma.com/design/uAk5EXin7OjHnndakSJzTk/Project?node-id=200-94679 (фрейм «1440»).
Старые страницы кейсов (черновики v2): `~/Documents/Kates Portfolio/cases/*.html`.

## Запуск

`python3 .devserver.py` → http://localhost:4322. Сервер поднимать из Bash в фоне.

## Правила

- **Тексты на сайте меняю только после «измени / пиши».** До этого — предложение списком «было → стало + зачем».
- **Метрика — только к своему проекту** и только со статусом «подтверждено» в `cases/`. «Примерно» допустимо, если Катя так сказала; выдуманного роста (две точки одного замера) не пишем.
- **Не упоминать прошлое в QA** (EX-QA, QA background) — просьба Кати.
- Публичная почта — `babenkocatherine@gmail.com`. Рабочую почту на сайт не ставить.
- **Мобилка** — только `mobile.css`, один `@media (max-width: 767px)`, без `!important` и inline-стилей; десктоп не трогать. Подробно — `directives/mobile.md` и `DESIGN-SYSTEM.md`.
- Заголовки карточек: Instrument Serif, первая часть Italic, остальное Regular.
- В Figma правлю только после согласования; перед мутацией перечитываю узел.
- Один вопрос к Кате — один раз. Новый вопрос сначала дописываю в `open-questions.md`, а не задаю в чате повторно.
